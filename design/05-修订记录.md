## 6. 原型的改动与自检

| 项 | 改动 |
|---|---|
| 断点 | 768–1023 保留左轨（修「无导航」）；右栏 <1200 收起；网格/瀑布 1/2/3；TOC 1024–1199 进 `<details>` |
| 令牌 | `stide` pack 真正写进 `app.css`（含亮/暗组合选择器），`--mc-h2/h3` 随人格派生 |
| 壁纸 | 按页默认（banner / solid）、文章页 transparent→full、八组亮暗参数 |
| 设置 | 右栏 Switch、字体双轴、动效档位接 `--mc-motion-scale`、语言只在壳页 |
| 持久化 | `localStorage` + 外部 `prefs.js`（首帧前应用，无内联脚本） |
| 搜索 | 去掉预填「高达」；空态三组；↑↓/↵ 可用；`?lang=en` 下仍能搜中文 |
| 印章 | 统一 20/72/160；左轨顶部放当前页印章 |
| 截图 | 重打 **22 张**（新增 `home-banner-1440.png`）；清单与实测见 `prototype/README.md` |
| 自检 | `prototype/verify.mjs`（17/17 PASS）与 `prototype/csp-check.mjs`（带 CSP 头 6/6 PASS；原型 UMD 需放行 `unsafe-eval`，生产构建不需要） |

> **返工说明**：本轮先把原型整体重写过一次，自绘控件替代了 `MProse`/`MSegmented`/`MSlider`/`MSelect`/`MSwitch`——偏离「用 Mochi」的路线，已整体撤回。现在这份是在**已验收基线**上的最小修改：界面件仍是 Mochi 组件，只改断点、pack、壁纸、持久化与搜索。
> 原型层仍未做：目录滚动高亮、「同一天」区块（数据里没有同日同人格的第二条）。这两项随 v1 工程补，不计入原型验收。
