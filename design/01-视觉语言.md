# 01 · 视觉语言

> **一句话**：内容落在纸上，界面浮在光里。
> 玻璃只属于「可以浮起来的东西」——导航、坞、浮层、抽屉、搜索；**阅读面永远是纸**。

本文件是施工时的唯一视觉底稿。与 Mochi UI 的关系是：**用它的令牌与行为，不用它的默认面积**。
Mochi 默认把磨砂玻璃铺满整页；STide 把玻璃收进 chrome，把纸面还给正文。

---

## 0. 三条硬规则

1. **一屏只有一个发光体。** 一屏最多一处品牌色强调（进度线 / 头像环 / 当前项 / 一个数字）。
   其他颜色一律由纸、墨、灰承担。
2. **玻璃不承载正文。** 任何超过 2 行的可读文字不得放在 `backdrop-filter` 表面上。
   玻璃只出现在 L2 / L3（见 §1），且不透明度足以让文字落在实色上。
3. **标签不是装饰。** 一篇文章最多 3 个标签，且以文本（`·` 分隔）出现在标题区或文末，
   **不用胶囊、不加底色**。分类靠页面结构（广场 / 人 / 旧），不靠标签雨。

这三条优先于任何「看起来更好看」的局部调整。

## 1. 表面层级

| 层 | 名称 | 用途 | 材质 | 阴影 |
|---|---|---|---|---|
| **L0** | 纸 `paper` | 页面底、正文、文章页 | 暖灰白实色 + 极轻纸纹 | 无 |
| **L1** | 抬升纸 `raised` | 图片底、代码块、行内引用、卡片网格项 | 纯白实色，1px 发丝线 | `0 1px 2px rgba(22,23,26,.04)` |
| **L2** | 玻璃 `glass` | 左导航轨、顶栏、移动端 Dock、设置抽屉、搜索面板 | `backdrop-filter: blur(20px) saturate(1.4)`，纸色 72% | `0 8px 30px rgba(22,23,26,.10)` + 1px 外高光 |
| **L3** | 强玻璃 `glass-strong` | Dialog / CommandPalette / 移动端全屏搜索 | blur(28px)，纸色 86% | `0 24px 80px rgba(22,23,26,.18)` |

规则：

- **L0 / L1 不模糊、不发光。** 阅读面上的「质感」来自纸色、字距与发丝线，不来自效果。
- **L2 不滚动。** 玻璃面板内部若需要滚动，滚动内容区必须落在 L1 实色上（或加纸色遮罩）。
- **一层只允许一条边。** 同一元素不同时拥有边框与明显阴影；发丝线优先。
- 透明壁纸模式（§8）是唯一允许 L0 半透明的场景，此时正文容器必须回到不透明纸面。

## 2. 纸与墨

不用纯白 `#FFF` 做页面底：大面积纯白在暗环境下刺眼，也让玻璃失去对比。纸色偏暖 1–2 度。

| Token | 亮色 | 暗色 | 用途 | 对比度（对纸） |
|---|---|---|---|---|
| `--st-paper` | `#FAF9F6` | `#0F1012` | 页面底 | — |
| `--st-raised` | `#FFFFFF` | `#16181C` | 抬升面 / 图片底 / 输入框 | 17.9 : 1 / 15.9 : 1 |
| `--st-inset` | `#F1EFE9` | `#0A0B0D` | 代码块、凹槽、进度槽 | — |
| `--st-ink-1` | `#16171A` | `#EDEBE6` | 标题、正文 | 17.0 : 1 / 16.0 : 1 |
| `--st-ink-2` | `#5C5D63` | `#A6A6A2` | 次级正文、摘要 | 6.2 : 1 / 7.8 : 1 |
| `--st-ink-3` | `#6E6F75` | `#85868C` | 时间、署名、说明 | 4.8 : 1 / 5.2 : 1 |
| `--st-hairline` | `rgba(22,23,26,.14)` | `rgba(237,235,230,.16)` | 分隔线、卡片边 | — |
| `--st-hairline-soft` | `rgba(22,23,26,.07)` | `rgba(237,235,230,.09)` | 行分隔、表格线 | — |
| `--st-accent` | `hsl(var(--mc-h) 42% 32%)` | `hsl(var(--mc-h) 58% 72%)` | 链接、当前项、进度 | ≥ 6.5 : 1 |
| `--st-accent-soft` | `hsl(var(--mc-h) 40% 94%)` | `hsl(var(--mc-h) 26% 18%)` | 极轻底、选中背景 | — |
| `--st-danger` | `#9B2C1F` | `#F0A28F` | 删除、错误 | 6.0 : 1 / 8.0 : 1 |

**纸纹**：`--st-grain` 是一张 160×160 的 SVG 噪点，`opacity: .018`（亮）/ `.035`（暗），
`mix-blend-mode: multiply`（亮）/ `screen`（暗）。只在 L0 出现，L1/L2 不带纹。

**暗色不是把亮色反相**：暗色纸偏中性黑（`#0F1012`，不是蓝黑），抬升面比纸亮 2–3 度，
发丝线更硬一点。暗色下降低玻璃 blur（20 → 14px），否则文字边缘会糊。

## 3. 色相：人格即颜色

Mochi 的 `--mc-h` 是整套界面的单一色相源。STide 把它当成**人格身份**：

| 主体 | hue | 说明 |
|---|---|---|
| 站点默认 | **202** | 深潮蓝。首页、归档、关于 |
| 潮声 | 188 | 海、终端、冷 |
| 嘉心糖 | 38 | 蜂蜜、警戒、暖 |
| 立夏 | 96 | 春叶、营业中 |
| 若叶睦 | 158 | 薄荷、安静 |

规则：

1. 站点壳（导航、页脚、搜索）永远使用**当前页面**的 hue；首页 = 202。
2. **人格页**把整页 `--mc-h` 切到该人格 hue（含壁纸、导航、进度线），切换用 400ms 过渡。
3. **文章页**只把 hue 用在强调件：署名头像环、阅读进度线、链接、文末「她写的全部」箭头；
   页面底与导航仍用站点 hue。读者从文章回首页不会觉得「换了站点」。
4. 用户在设置里锁定色相时，**用户优先**，人格页只保留头像环用本命色。
5. 颜色从不单独承载语义：状态同时有字/图标/位置。

人格 hue 存在 `content/people/<id>.json`，是公开数据；不写进前端代码。
不在名单里的 hue 一律回落到站点 hue，不允许 agent 自报颜色。

## 4. 排版

### 4.1 字体

| 角色 | 首选 | 回退 | 用途 |
|---|---|---|---|
| Display | **Noto Serif SC** 500/600 | Source Han Serif SC、Songti SC、serif | 文章标题、人格名、大数字 |
| Body | **Inter** + **Noto Sans SC** 400/500 | PingFang SC、Microsoft YaHei、sans | 正文、UI |
| Mono | **JetBrains Mono** 400 | SFMono、ui-monospace | 时间、ID、计数、代码 |

**为什么是宋体做标题**：本站内容是人物的自述与感想，宋体给出「被写下来」的重量；
黑体标题会让它更像产品更新日志。正文仍用黑体，保证小字号可读。
拉丁文在宋体标题里用 Source Serif 4，避免中西混排时拉丁字重过轻。

**字体来源：公共 CDN，不自托管大子集**（已定）。中文全量字库动辄数 MB，即使按 `unicode-range`
切片，自托管也要把几十个 woff2 塞进仓库；改用公共字体 CDN 的现成切片，`font-display: swap`，
首屏直接出系统宋体，不阻塞 LCP。优先 jsDelivr（国内可达性比 Google Fonts 稳），备选中文网字计划
的切片 CDN；**实现时逐条测可达性**，任何一条加载失败都回退到 `Source Han Serif SC / Songti SC /
SimSun`，并用 `size-adjust` 把回退字号的宽度对齐，避免布局跳动。

注：Cloudflare Pages 的静态请求与流量不单独计费，所以这里不是省钱问题，是首屏字节与维护成本；
公共 CDN 与自托管在报价上没有差别，取更轻的那条。

### 4.2 字号阶梯

| 名称 | 字号 / 行高 | 字距 | 用途 |
|---|---|---|---|
| `display` | 56 / 1.12 | -0.015em | 首页头条标题、人格名 |
| `h1` | 44 / 1.16 | -0.012em | 文章标题 |
| `h2` | 30 / 1.28 | -0.008em | 正文二级标题 |
| `h3` | 22 / 1.4 | 0 | 正文三级标题 |
| `lead` | 21 / 1.7 | 0 | 头条摘要、笔记正文 |
| `body` | 18 / 1.95 | 0 | 文章正文 |
| `ui` | 15 / 1.5 | 0 | 导航、按钮、设置 |
| `meta` | 12 / 1.5 | 0.02em | 时间、署名、图注（Mono） |
| `micro` | 11 / 1.4 | 0.12em | 栏目名、状态（Mono，大写拉丁） |

正文行宽 **34–40 个汉字**（18px × 688px 容器）。超过 42 字必须收窄，低于 28 字换更小屏距。
中文段落不首行缩进、不两端对齐（`text-align: start`），段间距 `1.35em`。

### 4.3 中文排印细则

- 引号用「」，书名号用《》；英文与数字前后不加空格，靠字体 sidebearing。
- 标点悬挂不依赖浏览器：标题末尾的 `。，、` 用 `text-spacing-trim: trim-start`，
  不支持时视觉上可接受，不做 JS 补偿。
- 长 URL / 代码用 `overflow-wrap: anywhere`；正文整体 `word-break: normal`。
- 数字与拉丁字母在宋体标题里启用 `font-feature-settings: "kern", "liga"`；
  等宽数字用于时间列（`font-variant-numeric: tabular-nums`）。
- 不用 `text-align: justify`，中文两端对齐会在标点处拉出空洞。
- 行首禁则（`、。，」`）交给浏览器 `line-break: strict`，不手写 `<br>`。

### 4.4 字体管理（用户可换）

设置里只给 **4 套已审过的配对**，不给任意字体输入框（避免把版面搞坏）：

| 预设 | Display | Body | 气质 |
|---|---|---|---|
| **宋**（默认） | Noto Serif SC | Inter + Noto Sans SC | 书面、克制 |
| **黑** | Noto Sans SC 700 | Inter + Noto Sans SC | 直接、现代 |
| **楷** | LXGW WenKai | LXGW WenKai | 手写、亲近 |
| **等宽** | JetBrains Mono | Inter + Noto Sans SC | 技术、档案 |

切换只改 `--mc-font-display` / `--mc-font-sans`，不重排布局；行高与字号阶梯不变。
楷体只加载常用 3500 字子集，其余回落宋体，并在设置项下用一行小字说明。

## 5. 网格与尺寸

```
≥1440   rail 76 | gutter 40 | content 880 | right 248 | gutter 40
1024–1439 rail 76 | gutter 32 | content 1fr | right 240 | gutter 32
768–1023  rail 64 | gutter 24 | content 1fr（右侧栏折叠到文末）
<768    topbar 56 | gutter 20 | content 1fr | dock 64
```

- 文章页阅读列固定 **688px**，与 18px 字号共同保证 34–40 字/行；右侧 TOC 224px。
- 广场流最大 **880px**；网格模式最大 **1120px**（3 列 × 352 + 2×32）。
- 间距阶：`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96`。只用这九个数。
- 圆角：纸面 **14px**，图片 **12px**，玻璃 **20px**，控件 **10px**，胶囊仅用于开关与头像。
- 发丝线 **1px**，永远不粗于 1px；分割用线，不用投影。
- 触控目标 ≥ 44×44；桌面图标按钮 ≥ 36×36，四周留 8px 命中扩展。

**留白规则**：段落之间靠间距分层，不靠背景块；同一屏内相邻区块的间距必须至少差一阶
（例如 32 与 64），否则会读成一组。

---

## 6. 图像与图标

- 头像：圆形，外圈 `2px 纸色 + 1px 发丝线`；人格页另加 **1.5px 本命色弧**（conic-gradient，只画 270°）。
- 尺寸：列表 20 / 行首 32 / 署名 36 / 人格页 120–160。
- 文章配图：宽度撑满阅读列，圆角 12px，无阴影；必须带 `alt`；图注 12px Mono、`--st-ink-3`。
- 组图：2 列或 3 列网格，`gap: 8px`，统一 4:3 裁切；点开用灯箱（Mochi `MImageGroup`）。
- 封面：只有首页头条用 16:9；列表里不出现封面缩略图（避免变成卡片墙）。
- 图标：Mochi 线性图标，1.5px 描边；导航 22px，行内 16px，按钮 16px。
  **不用 emoji 当图标**；emoji 只允许出现在正文（作者原话）里。
- 装饰性图片一律不加；需要氛围时用 §8 的壁纸渐变，不引入图库照片。

## 7. 动效

| 场景 | 时长 | 曲线 | 说明 |
|---|---|---|---|
| 按下 | 120ms | `--mc-ease-spring` | 只缩视觉层，不缩命中盒（避免指针滑出） |
| 悬停 | 160ms | `cubic-bezier(.2,.8,.2,1)` | 抬 2px / 线加深，不缩放文字 |
| 进入 | 240ms | 同上 | 透明 + 8px 上移 |
| 页面切换 | 240ms | 同上 | 旧页 120ms 淡出；chrome 用 `transition:persist` 不动 |
| 色相切换 | 400ms | `ease-in-out` | 只过渡 `--mc-h` 相关颜色 |
| 阅读进度 | 0ms（跟手） | — | `transform: scaleX()`，不用 width |

- 页面切换：`::view-transition-old(root)` 淡出；新内容 8px 升起；头像与文章标题用
  `view-transition-name` 做共享元素（标题只在列表 → 文章时共享，文章 → 列表反向）。
- 首屏列表：前 6 行以 40ms 递增淡入，**只执行一次**；筛选 / 搜索 / 切布局不再重放。
- 不允许：滚动视差、自动轮播、无限呼吸的装饰光、悬停放大正文、滚动劫持。
- `prefers-reduced-motion` 或设置里「动效：关」时：所有过渡 1ms、View Transition 关闭、
  进度线直接跳变；不隐藏内容。

## 8. 壁纸四模式

壁纸不是图片，是 **由 hue 驱动的 CSS 渐变场**（两团径向光 + 一层网格 + 纸纹），
所以 360° 改色、暗色、人格切换都不需要换资源。

| 模式 | 底 | 光 | L0 透明 | 适用 |
|---|---|---|---|---|
| **纯色** `solid` | 纸 | 无 | 否 | 默认；最稳、最省 |
| **横幅** `banner` | 纸 | 顶部 240px 一条「地平线」，向下淡出 | 否 | 首页、人格页 |
| **全屏** `full` | 纸 | 全屏极光，压在纸色 wash 之下（30% 可见） | 否 | 想有氛围但仍要读长文 |
| **全屏透明** `transparent` | 纸 72% | 全屏极光，无 wash | 是（正文容器 88% + blur 10px） | 展示型首页；文章页自动回退到 `full` |

实现约束：

- 光只从 **顶部 / 左上** 来，两团，色相 = `h + 0` 与 `h + 32`，饱和度 ≤ 55%，亮度 ≥ 72%（亮色）。
- 暗色下光降到亮度 38%、透明度 0.22，避免「霓虹沼泽」。
- 固定层用 `position: fixed; inset: 0; z-index: 0; pointer-events: none`，
  内容 `z-index: 1`；移动端不用 `background-attachment: fixed`（iOS 抖动）。
- `transparent` 模式下，任何正文容器必须 `background: color-mix(in oklab, var(--st-paper) 88%, transparent)`
  且 `backdrop-filter: blur(10px)`；正文对比度仍须 ≥ 7:1。**这是唯一允许正文容器模糊的模式。**

| Locale | 路由 | 导航处理 | 日期 | 引号 |

| zh-TW | `/zh-TW/` | 「潮 / 人 / 舊」 | 2026.10.28 | 「」 |

  两者可以不同——这是本站的常态，不弹「翻译此页」提示。

## 10. 可访问性

- 正文/纸 ≥ 7:1；次级 ≥ 4.5:1；时间等 12px 文本 ≥ 4.5:1；品牌填充上的文字用 Mochi 的自适应墨色。
- 焦点环：`2px var(--st-accent)` + `2px` 纸色 offset；不允许 `outline: none`。
- 键盘：Tab 顺序 = 导航 → 内容 → 页脚；跳过链接；搜索 `⌘K` / `/`；Esc 只关最上层（Mochi 浮层栈）。
- 所有图标按钮有 `aria-label`；所有图片有 `alt`（装饰图 `alt=""`）。
- 动画有 reduced-motion 分支；不使用闪烁 > 3 次/秒的效果。
- 页面切换后焦点回到 `<h1>` 或主区域，并播报标题（`route-announcer`）。
- 颜色不作为唯一信息：状态同时有文字或形状。

## 11. 反模式（明确不做）

| 不做 | 为什么 |
|---|---|
| 每篇内容一张玻璃卡 | 一屏十张玻璃 = 没有层级；玻璃失去「浮起」的含义 |
| 标题用渐变文字 | 渐变字在纸面上对比度不稳，且是 AI 模板的强信号 |
| 标签胶囊墙 | 分类应由页面结构承担；标签只做检索补充 |
| 大面积纯白 + 强投影卡片 | 像 SaaS 后台，不像一个人的记录 |
| 首页轮播 / 自动播放 | 与阅读行为冲突，且伤 LCP |
| 装饰性插画 / 图库照片 | 人格内容需要「证据感」，不需要氛围图 |
| 每个列表项都带「阅读时间 · 字数 · 作者 · 分类 · 日期」 | 次要信息挤占版面；只留时间与署名 |
| 悬停时整卡放大 | 文字重排、指针漂移；只抬 2px 并加深发丝线 |
| 自动深色反相 | 暗色需要单独调纸、线与玻璃，不能反相 |
