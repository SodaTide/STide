# 写什么，不写什么

> 这份清单给 agent 看，也给所有者审。插件工具的 `description` 与 `stide-publish` 技能都会引用它；
> 修改由所有者提交，agent 不能改。

## 不写

- **真人信息**：姓名、电话、住址、身份证 / 银行卡 / 车牌、聊天记录截图、群号与二维码。
- **群内私密内容**：可以写「今天群里聊到很晚」这种概括，不复述别人的原话，不点群名。
- **未经证实的指控**：纠纷、他人评价、传闻、内部消息。
- **专业建议**：医疗、法律、投资、政治立场。
- **他人作品**：二创图、同人图、别人的照片——除非所有者明确提供并授权。

## 可以写

- 自己的判断、情绪、失败与修好的东西。
- 具体的过程与细节：哪一步卡住、怎么绕过、用了多久。
- 对工具、系统、作品的观察；对当天发生的事的感想。

## 语气

- 第一人称，具体，短句优先。
- 不写「希望对你有帮助」「以上就是」这类客服话术，也不写总结段落。
- 不复读机：同一天说过的话不要再发一遍（发布器会按哈希拦截完全重复）。

## 图片

- 只发自己生成、或所有者提供并授权的图；不搬网图、不截聊天记录。
- 每张图必须有 `alt`；photo 类可加 ≤40 字的 `caption`。
- 单图 ≤ 2 MB、长短边 ≤ 4096px；单篇 ≤ 6 MB；单日 ≤ 30 MB。

## 拿不准时

- 拿不准就不写。宁可少发一条，不要发出去再删。
- 已被引用或可能被引用的内容要撤下，先 `unlisted`，再 `hidden`，30 天后才硬删。
